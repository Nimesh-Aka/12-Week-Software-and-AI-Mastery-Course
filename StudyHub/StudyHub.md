Phase 1 — Linux, networking and Docker

Start here

Learn what a server actually is, Linux commands, ports, DNS, HTTP/HTTPS, environment variables, processes, and logs. Then package your FastAPI backend in Docker.

Build: Run StudyHub in a container on your own computer.

Phase 2 — CI/CD and automated testing

Learn GitHub Actions, test automation, build pipelines, deployment strategies, and rollback. Understand where Jenkins fits and why you don't need both tools immediately.

Build: Every push runs tests, and approved changes can deploy automatically.

Phase 3 — AWS cloud fundamentals

Learn IAM, VPC, subnets, security groups, EC2, SSH, storage, billing, and cloud security.

Build: Deploy your Dockerized backend onto an AWS virtual machine.

Phase 4 — Production architecture

Learn load balancers, reverse proxies, HTTPS, health checks, managed databases, backups, secrets, and infrastructure as code using Terraform.

Build: A more secure, repeatable deployment with clear recovery procedures.

Phase 5 — Scaling to thousands of users

Learn load testing, caching with Redis, database indexing, connection pooling, background jobs, queues, horizontal scaling, and autoscaling.

Build: Test where StudyHub becomes slow and remove the actual bottlenecks.

Phase 6 — Kubernetes and container orchestration

Learn Pods, Deployments, Services, Ingress, configuration, secrets, resource limits, autoscaling, and rolling updates.

Build: Run and manage multiple copies of your application using Kubernetes.

Phase 7 — Observability and reliability

Learn metrics, logs, traces, alerting, incident response, rate limiting, disaster recovery, and reliability targets.

Build: Detect failures, find their causes, and recover without guessing.
